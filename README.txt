BHAKIYALAKSHMI ENTERPRISES WEBSITE
==================================

Files:
- index.html              Main homepage
- contact.html            Team contact directory with email and call buttons
- computer-amc.html       Computer AMC service page
- printer-amc.html        Printer AMC service page
- system-rental.html      System rental service page
- manpower-agency.html    Manpower agency service page
- assets/style.css        Shared responsive styles and animations
- assets/script.js        Scroll reveal, back-to-top and enquiry form

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox. Open contact.html to view the team contact directory.
3. An internet connection is required for Bootstrap, Bootstrap Icons and Google Fonts CDN assets.

BEFORE PUBLISHING
1. The visible business email is set to vijay.a@dhruvinfotec.co.in. The email address in assets/script.js is also set to this address.
2. The business location is set to Uthiramerur, Tamil Nadu, India. Add your business phone number if you want it displayed.
3. The enquiry form currently prepares an email using the visitor's default email app (mailto). For server-side form submissions, connect it to a backend or form service.
4. Check service scope and wording to match the services your business actually provides.

Built with Bootstrap 5.3.3.
